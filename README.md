# Spam Email Classifier

A machine learning project to classify emails as **Spam** or **Not Spam** using Python and Scikit-learn.

## 🚀 Features
- Preprocessing of email text (tokenization, stopword removal, TF-IDF vectorization).
- Training with machine learning models (e.g., Naive Bayes, Random Forest).
- Evaluation using accuracy, precision, recall, and F1-score.
- Interactive Streamlit app for uploading CSV files and testing emails in real-time.

## 🛠️ Tech Stack
- Python
- Scikit-learn
- Pandas
- Streamlit
